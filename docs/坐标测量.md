# 换版式时怎么测格子坐标

如果你要把 `templates/tpl_p*.png` 换成自己学校的模板，需要重新测格子坐标，
写进 `scripts/fill_template_v3.py` 顶部的 `P1` / `P2` / `BEIFEN1` / `BEIFEN2`。

**不要靠肉眼估坐标，也别让视觉模型看图给坐标——它会偏，而且你无法复核。**
一律用像素扫描量，量完出可视化图复验。

## 1. 模板图规格

- 200dpi 的 A4 = **1653 × 2339** 像素
- 如果模板是 PDF，先转图：

```python
import fitz
d = fitz.open("教学设计模版.pdf")
for i, p in enumerate(d):
    p.get_pixmap(dpi=200).save("templates/tpl_p%d.png" % i)
```

## 2. 扫横线（行界）

某一行在表格宽度内暗像素占比很高，就是横线：

```python
import numpy as np
from PIL import Image

a = np.array(Image.open("templates/tpl_p0.png").convert("L"))
dark = (a < 140)

rowratio = dark.mean(axis=1)
rows = [y for y in range(a.shape[0]) if rowratio[y] > 0.5]

def group(v, gap=4):          # 相邻的合并成一条线
    out, s, p = [], v[0], v[0]
    for x in v[1:]:
        if x - p <= gap: p = x
        else: out.append((s, p)); s = x; p = x
    out.append((s, p))
    return out

for g in group(rows):
    print("横线 y=%d~%d" % g)
```

## 3. 扫竖线（列界）

竖线要在**相邻两条横线之间**扫，否则会把字的笔画当成线：

```python
seg = dark[y0:y1, :]                  # 只看某一行带
ratio = seg.mean(axis=0)
cols = [x for x in range(a.shape[1]) if ratio[x] > 0.75]
print(group(cols))
```

## 4. 可视化复验（必做）

坐标写死后，出一张叠线图用眼睛确认一次，比反复改数字快得多：

```python
from PIL import ImageDraw
img = Image.open("templates/tpl_p0.png").convert("RGB")
d = ImageDraw.Draw(img)
for y in YS:                # 你的横线 y 列表
    d.line([(0, y), (img.width, y)], fill=(255, 0, 0), width=2)
for x in XS:
    d.line([(x, 0), (x, img.height)], fill=(0, 0, 255), width=2)
img.save("_lines_check.png")
```

红=横线、蓝=竖线。漏了哪条、错位在哪，一眼就看得出来。

## 5. 填进常量

```python
P1 = {
    "topic":      (389, 344, 837, 431),    # (x0, y0, x1, y1) 左上、右下
    "type":       (941, 344, 1134, 431),
    ...
}
```

**合并单元格没有内部竖线**，从 PDF 矢量反推会出错（`get_drawings()` 拿到的线是分段画的）。
直接按「这条横线到那条横线、这条竖线到那条竖线」框出矩形，然后用第 4 步的可视化图核对。

## 6. 窄栏字号别硬塞

教学环节栏只有 143px 宽，字号放大后一行只放得下两个字。
`fill_steps_column()` 已经处理成「每项单独一行、项间均匀分布」，
你只要保证 `steps` 里每项 ≤4 字、3~4 项。

## 常见坑

| 现象 | 原因 | 修法 |
| --- | --- | --- |
| 字压到格线上 | 可用宽算大了 | 内宽取 `栏宽 - 24~30`，别取满 |
| 最后一行的字被切一半 | 行距 + 行数超过格高 | 降 1~2 号字号，或减内容 |
| 竖栏文字被拆成两行 | 四个字正好等于内宽 | 内宽再留 4px 余量 |
| 整页只有表头 | 行高设成固定值超出页面 | 用 AUTO 让内容撑开 |
